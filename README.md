# PublicOS

Shareable Claude skills from my personal "self OS" (DiogoOS). Each skill is a folder under `skills/` with a `SKILL.md` and supporting `references/`.

| Skill | What it does |
|---|---|
| `agent-builder` | Socratic interview that recommends a workflow/agent pattern (Anthropic's "Building Effective Agents") and drafts a SKILL.md skeleton |
| `de-risk-this` | Interrogates a product idea, roadmap or team using Marty Cagan's four risks (*Inspired*) |
| `structure-this` | Structures emails, decks and docs answer-first using Barbara Minto's Pyramid Principle |

## Use

Copy a skill folder into `~/.claude/skills/` (or a project's `.claude/skills/`).
